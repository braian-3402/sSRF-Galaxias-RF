# galaxy-ssfr-prediction-rf
# Datos

Los datos originales no se incluyen en este repositorio debido a su tamaño y a que pertenecen a fuentes externas.

## Fuente

- Archivo utilizado: `dr7MPA_WISE_WISC.fits`

## Preparación de los datos

Para reproducir el análisis:

1. Descargar el archivo original desde la fuente indicada.
2. Guardarlo en `data/raw/`.
3. Ejecutar el script de preprocesamiento incluido en el repositorio.

El archivo esperado es:

`data/raw/dr7MPA_WISE_WISC.fits`

El conjunto de datos utilizado fue proporcionado por el equipo docente para fines académicos y combina información fotométrica y espectroscópica de galaxias. Los archivos originales no se incluyen temporalmente en este repositorio mientras se verifica su procedencia y licencia de redistribución. Se documentan las variables empleadas y el procedimiento completo de preprocesamiento para garantizar la transparencia metodológica.
