# Datos

El análisis utiliza el archivo:

`dr7MPA_WISE_WISC.fits`

Este archivo combina información fotométrica y espectroscópica de galaxias, incluyendo datos de MPA-JHU/SDSS, magnitudes WISE y coeficientes PCA de Wisconsin.

## Disponibilidad

Los datos originales no se incluyen en este repositorio debido a su tamaño y a que se está verificando el procedimiento adecuado para su redistribución.

## Fuentes y documentación

- [SDSS SkyServer DR16](https://skyserver.sdss.org/dr16/en/home.aspx)
- [Wisconsin PCA - SDSS](https://www.sdss.org/dr16/spectro/galaxy_wisconsin/)
- [Kauffmann et al. (2003)](https://ui.adsabs.harvard.edu/abs/2003MNRAS.341...33K/abstract)

## Ubicación esperada

Para ejecutar el análisis localmente, el archivo debe guardarse en:

`data/raw/dr7MPA_WISE_WISC.fits`

La carpeta `data/raw/` está excluida del control de versiones para evitar la publicación accidental de archivos grandes.
